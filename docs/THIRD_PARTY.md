# Third-party resources

| Resource | Use | Maintainer reference |
| --- | --- | --- |
| ExDark | Images and bounding-box annotations | https://github.com/cs-chan/Exclusively-Dark-Image-Dataset |
| BDD100K | Detection images, labels and condition metadata | https://bdd-data.berkeley.edu/ |
| Ultralytics | YOLOv8n, YOLOv10n and RT-DETR inference | https://github.com/ultralytics/ultralytics |
| PyTorch and torchvision | Tensor operations and pretrained Faster R-CNN | https://github.com/pytorch/vision |
| COCO API | Detection evaluation | https://github.com/cocodataset/cocoapi |
| scikit-learn | Logistic regression, encoding and reliability metrics | https://scikit-learn.org/ |

EigenCAM saliency follows Muhammad and Yeasin (2020). The implementation is in
`src/xai_stability.py`.

Dataset files, pretrained checkpoints and serialized experiment models are not bundled.
Refer to each upstream project for its license, access conditions and citation requirements.
This repository does not grant additional rights to those resources.
